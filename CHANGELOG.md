## [1.0] - 2026-10-07

- Add ASCII rendering for terminals without Braille font support.
- Support thumbnail gallery with 4- and 9-image layouts.
- Add Atkinson dithering.
- Improve video playback, including support for up to 10 FPS.
- Improve seeking in short videos.
- Increase image brightness and improve rendering and navigation.

## [0.2] - 2026-07-31

- Add video playback with seek controls.
- Add a two-line status bar for item and playback information.
- Improve video seeking and handling of repeated seek keys.

## [0.1] - 2026-07-29

- Initial release of dotz for rendering images as colored Braille art in the terminal.
- Add directory navigation, slideshow, zoom and pan, image rotation and flipping.
- Add file metadata and an in-app keyboard help screen.
- Optimize image loading and rendering with background processing.
